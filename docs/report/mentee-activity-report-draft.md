## ① 프로젝트 목표 및 진행 과정

### 프로젝트 목표

특정 상용 앱에 종속되지 않고, **원본으로 되돌아갈 수 있으며 검증된 지식만 장기 보관되는** 개인 지식관리(PKM) 시스템을 구축하는 것이 목표다. 자료를 많이 모으는 것이 아니라, 출처가 연결된 지식이 재사용 가능한 형태로 누적되는 구조를 만드는 데 초점을 두었다.

세부 목표는 네 가지다.

1. **증거 보존** — 논문·웹·영상 원본을 수정 불가 상태로 Markdown에 고정하고, 출처 식별자와 SHA-256으로 복구 경로를 확보한다.
2. **지식 컴파일** — 반복 사용할 개념·엔티티·비교·질의만 정본(canonical) 문서로 승격한다.
3. **탐색 보조** — NotebookLM 질의와 지식그래프로 연구 공백·연결 후보를 찾되, 이를 정본으로 취급하지 않는다.
4. **사람 승인 관문** — 자동화가 수집·검사·후보 생성을 담당하고, 지식 승격 판단은 사람이 소유한다.

이 목표를 실제 도메인으로 검증하기 위해, 시험 주제로 **UAV(드론) 군집 제어·경로계획 문헌 조사**를 선정했다.

### 진행 과정

## ④ 활동 소감 *(최종보고서에만 반영 — 초안 메모)*

### 좋았던 점

- 도구를 늘리는 대신 **계층과 책임을 먼저 정의**한 것이 가장 큰 효과였다. 규칙이 문서로 고정되어 있어 작업이 중단되었다 재개될 때도 같은 품질을 유지할 수 있었다.
- 자동화와 사람 판단의 경계를 명시한 덕분에, AI가 만든 요약을 검증 없이 지식으로 남기는 문제를 구조적으로 막을 수 있었다.
- UAV 군집이라는 실제 도메인에 적용해 보며, 설계가 문서상으로만 그럴듯한 것이 아님을 확인했다.

### 아쉬웠던 점

- 출판사 접근 제약으로 논문 9편 중 2편만 원문 PDF를 확보해, 일부 정본 문서가 초록 수준 근거에 머물렀다.
- 자동화 단계에서 외부 서비스의 무료 사용 한도·차단 정책에 막히는 구간이 있어, 예상보다 수동 개입이 필요했다.
- 협업 이력을 초기부터 정형화하지 못해, 보고서 작성 시점에 일부 활동 기록을 사후 정리해야 했다.

### 향후 계획

1. 미확보 논문의 원문을 기관 접근 경로로 확보하고, 이를 근거로 정본 문서의 신뢰도를 재평가한다.
2. 주간 자동 리포트를 4주 이상 운영해 자동화 안정성을 검증한다.
3. 지식그래프에서 도출된 연결 후보를 사람 검증 절차에 태워, 실제 연구 질문으로 확장한다.
4. 구축한 계약과 파이프라인을 다른 연구 주제에 그대로 재사용해 이식성을 확인한다.

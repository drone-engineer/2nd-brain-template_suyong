this page PX4 Autopilot User Guide [링크: #px4-autopilot-user-guide] ​ [링크: https://github.com/PX4/PX4-Autopilot/releases] [링크: https://discuss.px4.io//] [링크: https://discord.com/invite/dronecode] PX4 is an open-source autopilot for drones and autonomous vehicles. It runs on multirotors, fixed-wing, VTOL, helicopters, rovers, and more. This guide covers everything from assembly and configuration to flight operations and development. WARNING This guide is for the development version of PX4 ( main branch). Use the Version selector to find the current stable version. Documented changes since the stable release are captured in the evolving [링크: ./releases/main] release note . Try PX4 [링크: #try-px4] ​ No hardware needed. Run PX4 in simulation with a single command using [링크: ./simulation/px4_simulation_quickstart] Docker or a .deb package . Connect [링크: https://qgroundcontrol.com] QGroundControl , [링크: https://mavsdk.mavlink.io/] MAVSDK , or [링크: ./ros2/] ROS 2 and start flying immediately. This covers sensor calibration, flight mode setup, and tuning. Hardware [링크: #hardware] ​ The [링크: ./hardware/drone_parts] Hardware Selection &amp; Setup section covers flight controllers, sensors, telemetry, RC systems, and payloads. See [링크: ./payloads/] Payloads for camera and delivery integrations. Fly [링크: #fly] ​ Read [링크: ./config/operations] Operations to understand safety features and failsafe behavior before your first flight. Then see [링크: ./flying/basic_flying_mc] Basic Flying (Multicopter) or the equivalent for your frame type.

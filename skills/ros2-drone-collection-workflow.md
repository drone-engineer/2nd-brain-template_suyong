# ROS2 드론 기술 수집 워크플로우

이 워크플로우는 ROS2 기반 드론 기술 정보를 정기적으로 수집하고 정리하는 절차입니다.

## 작업 단계

1. **데이터 수집**
   - GitHub Search API를 통한 최신 프로젝트 검색
   - 공식 문서 (PX4, ArduPilot, ROS2)에서 릴리즈 노트 및 문서 수집
   - 기술 뉴스 및 논문에서 관련 정보 추출

2. **데이터 정제**
   - 수집된 내용을 Markdown 형식으로 정리
   - 출처 표기 및 sha256 해시 검증
   - 정해진 스키마에 맞게 프론트매터 작성

3. **지식 정리**
   - 개별 기사들을 종합하여 보고서 작성
   - 주제별 분류 및 링크 생성
   - 인덱스 업데이트

4. **검증 및 커밋**
   - Gate B 검증 수행 (파일 무결성, 프론트매터 유효성)
   - Git에 변경사항 커밋 및 푸시
   - 로그 작성

## 자동화 기능

- `daily-collect-2026-08-05.py` 스크립트를 사용하여 자동 수집
- `check-gate-b-2026-08-05.py` 스크립트로 자동 검증
